### 1.3 3 秒轮询边沿触发

**验证目标**：poll 循环只在 connectedSub **变化**时处理，不再每轮回填

**验证结果**：
```csharp
// ✅ UseEffect 里的 poll 循环
Task.Run(async () =>
{
    string lastConnectedSub = "";
    bool firstPoll = true;
    
    while (!cts.IsCancellationRequested)
    {
        string text2 = await VpnSession.ConnectedSubAsync();
        
        if (firstPoll)
        {
            // 首轮只记基线，不判定
            firstPoll = false;
            lastConnectedSub = text2;
            if (text2.Length > 0 && text2 != _subActive.Id)
            {
                RollingLog.Info("profile-sub-adopt", 
                    "启动基线：隧道连着 {text2}，生效记为 {_subActive.Id}；不自动回填");
            }
        }
        else if (text2 != lastConnectedSub)  // ✅ 边沿触发：只有变化才处理
        {
            string text3 = lastConnectedSub;
            lastConnectedSub = text2;
            
            if (text2.Length > 0)
            {
                // 系统侧连接到新订阅 → Adopt
                SubscriptionManager.Result result = await SubscriptionManager.AdoptAsync(text2);
                if (result.Ok)
                {
                    _setActionHint(result.Message);
                    await RefreshSubscriptionsAsync();
                }
            }
            else
            {
                // 系统侧断开 → 只记日志，不撤销生效订阅
                RollingLog.Info("profile-sub-adopt", 
                    "系统侧连接已断开（此前 " + text3 + "），生效订阅保持不变");
            }
        }
    }
});
```

**结论**：✅ 边沿触发逻辑正确，app 内切订阅不会被自己撤销。

## 四、已知限制（无需修复）

1. **MakeId 带 token**：订阅路径里的 token 会出现在文件名/profile 名/日志里。换 id 需迁移，不在本批范围。
2. **老订阅不会自动获得新名字**：升级后要再点一次「更新当前订阅」才会把响应头名字补进 settings.txt。
3. **PowerShell Add-AppxPackage 不可用**：此环境 exit code 127，MSIX 必须手动双击安装。
